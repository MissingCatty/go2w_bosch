## 快速结论

当前已经形成的链路是：

```text
XT16/IMU -> LIO-SAM -> Web 静态膨胀自由区中心 A*
                         -> SCAN 实时局部 A* + B 样条
                         -> 实时雷达完整双圆柱碰撞
                         -> 隔离速度话题
                         -> 主机安全门
                         -> Unitree Sport API
```

系统已经具备导航地图后处理、自动地图配准、全局/局部路径、Web 可视化、地图非破坏性修图、键盘遥控、姿态控制、一键启动和真实底盘安全门。

发生过的最严重问题是 2026-08-16 的真实撞障：障碍靠近后进入雷达盲区，被第一版“3 秒自动过期”错误删除，规划器误判道路恢复并继续直行。当前已改成近处 0.8 m 内不按时间删除、点云双看门狗和连续 3 帧确认后才恢复。

最新一轮曾因静态膨胀图上的完整双圆柱朝向检查，把实际可能可转的起点提前判死。现在已改为：静态图只规划已经膨胀的中心通路，SCAN 根据实时雷达检查完整前后双圆柱，静态图在局部层只保留中心防穿墙兜底。目标 `(4.38, 3.16)` 已在底盘锁定条件下回归成功；倒车/侧移仍未进入全局运动学，但不再是中心线全局规划的前置阻塞条件。

## 当前优先事项

1. 在受控、软质障碍条件下实机验证新的“静态中心 + 实时完整足迹”分层，重点覆盖贴墙旋转、短时漏检和小配准误差。
2. 评估狭窄起点是否仍需要倒车/侧移机动层，并补完整的纯 yaw 局部转向阶段。
3. 对机身/雷达支架自反射增加显式自过滤并做录包回归。
4. 验证近距盲区、长时间静止幽灵点、拐角绕障和点云断流恢复。
5. 玻璃门使用可靠外部状态、AprilTag、RGB-D 或人工门禁；当前强度检测原型已经撤回。
6. 楼梯导航仍需多层/高程状态格和地形碰撞模型，当前尚未实现。
